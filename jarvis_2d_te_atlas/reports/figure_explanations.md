# 图 1 详细说明 —— 二维热电设计规律总览
## figures/design_rules_overview.png（+ .pdf）

**数据来源**：JARVIS dft_2d，共 1103 个二维材料（n 型输运 806、p 型 803）。

**全局配色**：面板 (a)(c) 用 magma 色阶表示 log₁₀(ZT_e)（从深紫≈0 到亮黄≈高值）；面板 (b) 用蓝= n 型、红= p 型；面板 (d) 用 viridis 表示配对的最低 ZT_e。

**核心量 ZT_e 的定义**（务必理解）：
真实热电优值 ZT = S²σT / (κ_e + κ_L)。由 Wiedemann–Franz 定律 κ_e ≈ LσT（本项目已在数据里验证 σ 与 κ_e 相关 r≈0.96），
消去 σ 后得到**电子贡献的 ZT 上限**：
    ZT_e = S²σT / κ_e ≈ S² / L ，L = 2.44×10⁻⁸ W·Ω/K²
即 ZT_e 只由 Seebeck 系数 S 决定，与电导率无关；真实 ZT 恒小于 ZT_e（因为还要除以 κ_L）。
因此本图严格来说是"高 ZT 天花板流形"，不是完整 ZT——这是 JARVIS dft_2d 缺 κ_L 数据导致的诚实边界。

---

## 面板 (a)：p 型 joint manifold 按 ZT_e 着色（主图）

- **横轴 Φ₁**：joint manifold 的第一主方向，即"电子结构质量轴"。
  实测它与 ZT_e、|S|、E_g、有效质量 m* 的 Spearman 相关为 **-0.82 ~ -0.89**，与 log σ 相关为 **+0.77 ~ +0.80**。
  即：Φ₁ 负端 = 半导体（宽带隙、重有效质量、高 Seebeck、高 ZT_e）；Φ₁ 正端 = 金属（E_g=0、轻有效质量、S≈0、高 σ）。
- **纵轴 Φ₂**：第二主方向，承载残余的输运谱信息。
- **颜色**：log₁₀(ZT_e)，亮色 = 高 ZT_e 天花板。
- **⭐ 星号**：ZT_e > 2 那批材料的质心，标出"high-ZT_e region"。
- **读图结论**：高 ZT_e 不是散布的，而是**流形里一个清晰、连通的角落**（Φ₁ 负端 + 半导体区）。这就是"高 ZT 流形"在电子天花板意义下的位置。

## 面板 (b)：高 ZT_e 需要带隙

- **横轴**：OptB88vdW 带隙 E_g (eV)；**纵轴**：ZT_e（对数坐标，范围 10⁻³ ~ 40）。
- **颜色**：蓝 = n 型，红 = p 型。
- **关键特征**：E_g ≈ 0 的金属簇全部塌在 ZT_e ≈ 0（图左下，标注"metals (S≈0)"），因为金属 Seebeck 系数趋近 0 → ZT_e = S²/L ≈ 0。
- **数值**：ZT_e 与 E_g 的 Spearman 相关 n 型 +0.63、p 型 +0.76（强正相关）。
- **读图结论**：**高 ZT_e 的必要条件是半导体带隙（E_g > 0.5 eV），金属不可能高 ZT_e。**

## 面板 (c)：Seebeck–电导率权衡（热电两难）

- **横轴**：|S|（Seebeck 绝对值，μV/K）；**纵轴**：log₁₀ 电导率尺度。
- **颜色**：log₁₀(ZT_e)。
- **关键特征**：图中呈一条"从左上到右下"的对角带状分布——
  - 左上 = 金属：σ 极高、|S|≈0 → ZT_e≈0（深紫）；
  - 右下 = 大带隙半导体：|S| 高、σ 低 → ZT_e 高（亮黄）；
  - 中间 = 高 ZT_e 材料集中在"高 |S| + 中等 σ"的角落。
- **物理机制**：S ∝ m*·E_g（重有效质量 + 大带隙 → 高 Seebeck），而 σ ∝ 1/m*（轻有效质量 → 高电导率）。二者对有效质量的要求相反，构成根本权衡。
- **读图结论**：设计目标是**在保持足够 |S| 的前提下尽量拉高 σ**——即中等有效质量、中等带隙的最优窗口。

## 面板 (d)：超晶格候选对

- **横轴**：晶格失配（%）；**纵轴**：Seebeck 对比 |S_n − S_p|（μV/K）。
- **颜色**：该材料对的 min(ZT_e)（两端中较低的那个，代表瓶颈）。
- **每个点**：一个"n 型材料 + p 型材料"的异质结候选，共 298 对。
- **红色虚线**：失配 < 0.5% 的高共格区（左侧 = 可外延生长的候选）。
- **读图结论**：优先取**虚线左侧（晶格可共格）+ 纵轴高（输运对比大）+ 亮色（两端 ZT_e 都高）**的点——这就是流形指导超晶格设计的具体判据。
- **注意**：真实 ZT 还需 κ_L，超晶格的热电增益（界面声子散射降 κ_L）必须用 κ_L 数据才能验证，本图只给出候选池。

# 图 2 详细说明 —— 高 ZT_e 流形主图
## figures/high_ZT_manifold.png（+ .pdf）

- **两栏**：(a) n 型、(b) p 型，各自由其独立的 joint manifold 坐标 Φ₁–Φ₂ 张成。
- **颜色**：log₁₀(ZT_e)（magma），⭐ = ZT_e>2 区域质心。
- **为什么 n/p 分开展示**：n 型与 p 型的 joint 空间是分别对齐得到的（二者 Φ 坐标不可直接比较），且 p 型整体更强（ZT_e>2 的材料 p 型 378/803 vs n 型 131/806）。
- **读图结论**：两种载流子类型各自都呈现同一个规律——**高 ZT_e 集中在 Φ₁ 的同一侧**（半导体+重质量端），金属端始终 ZT_e≈0。这从几何上验证了"高 ZT 天花板 = 高 Seebeck = 宽带隙+重有效质量"的设计规则。
