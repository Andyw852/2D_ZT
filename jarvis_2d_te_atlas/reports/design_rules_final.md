# 最终报告：二维热电设计规律 + 高ZT天花板流形 + 超晶格候选池

> 数据：JARVIS dft_2d（1103）+ Magpie 补强描述符。
> 诚实边界：无 κ_L → 给出电子 ZT 上限 ZT_e^WF = S²/L（固定金属 Lorenz 常数 L=2.44e-8 的 WF 上限，非完整 ZT）。注意 ZT_e^WF ∝ S² 是**定义使然**（只含 Seebeck），其「高 ZT_e 由高 S 主导」不构成独立发现；真实 ZT = S²σT/(κ_e+κ_L) 需 σ、κ_e、κ_L（κ_L 由 MACE 声子计算给出）。

## 一、五条初步设计规律（全部由真实数据得出）

**规律 1：高 PF 由 |Seebeck| 主导，不是电导率。**
logPF vs |S|：Spearman +0.52~0.62；vs logσ：**-0.14~-0.22**（负相关）。
高 PF(top20%) 的 |S|≈203-263 μV/K vs 低 PF 9 μV/K（21-29 倍），且 σ 反而更低。
→ 金属（高σ、S≈0）的 PF 极低；**高 PF 必须来自高 Seebeck 的半导体。**

**规律 2：电子 ZT 上限 ZT_e^WF = S²/L（固定金属 L 的 WF 上限，定义使然）。**
此定义下 ZT_e 与电导率无关、只由 Seebeck 决定，是**定义使然**（ZT_e^WF ∝ S²），
不构成对 σ/κ_e 的独立验证；真实 ZT = ZT_e^data × κe/(κe+κL)，其中 ZT_e^data = S²σT/κe
用数据本身（注：JARVIS nkappa 与 ncond 缩放不一致，见 40_zte_ceiling.py 单位核对），
且必须除以 (κe+κL)（κ_L 由 MACE 声子计算给出）。

**规律 3：高 ZT_e^WF（=高 |S|，定义使然）需要「宽带隙 + 重有效质量」。**
ZT_e vs Eg：Spearman +0.63/+0.76；vs m*：+0.78（n 与 p 型一致）。
p 型整体更强：ZT_e>2 的 378/803（n 型仅 131/806）。

**规律 4：S–σ 权衡（热电两难）。**
ZT_e ∝ S² 倾向重质量+大带隙；PF ∝ S²σ 还需要中等 σ。最优在中等带隙/质量区间。

**规律 5：结构不能筛热电材料（补强后仍成立）。**
即便 Magpie 描述符，结构→输运相关≈0；结构→Eg 仅 0.11。**必须算电子结构（Eg、m*）。**

## 二、高 ZT 天花板流形（consensus 空间）

Joint property manifold 的 **Φ1 主轴就是"电子结构质量轴"**：
- Φ1 与 ZT_e / |S| / Eg / m* 相关 -0.82~-0.89，与 logσ +0.77~+0.80。
- 一端 = 半导体（Eg≈1.7-2.1 eV、重 m*、高 S、ZT_e>2）；另一端 = 金属（Eg=0、S≈0、ZT_e≈0、高 σ）。
- **高 ZT_e 区域 = 流形中明确的"宽带隙+重质量"角落**，与金属区在 Φ1 上清晰分离。
