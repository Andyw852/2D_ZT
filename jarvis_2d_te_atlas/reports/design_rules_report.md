# 初步设计规律报告：2D 热电材料的参数关联与高 ZT 天花板定位

> 基于现有 JARVIS dft_2d（1103 材料）+ 补强的 Magpie 结构描述符。
> 诚实边界：**无 κ_L 数据，因此只能给出电子 ZT 上限 ZT_e^WF = S²/L（固定金属 L 的 WF 上限），不能给出完整 ZT。** 注意 ZT_e^WF ∝ S² 是定义使然（只含 Seebeck），「高 ZT_e 由高 S 主导」不构成独立发现。

## 一、补强结构描述符后，关键负结果是否改变？

| property | 旧(Hellinger+SOAP) | 新(Magpie+SOAP) | 结论 |
|---|---:|---:|---|
| Eg | 0.058 | **0.112** | 提高近一倍，但仍弱 |
| S_median | 0.001 | -0.001 | **仍为零** |
| log_sigma | 0.052 | 0.052 | 不变 |
| PF | -0.011 | -0.030 | **仍为零** |
| 仅 composition→Eg | 0.001 | **0.122** | Magpie 大幅修复 |

结论：**"结构↛输运"是稳健的，不是弱描述符伪影**。但"结构→带隙"被 Magpie 部分修复（0→0.11），
说明组分电负性/原子质量确实部分决定金属 vs 半导体，但**输运（S、σ、PF）与结构本质去相关**。

## 二、初步设计规律（全部由真实数据得出）

### 规律 1：高 PF 的第一决定因素是 |Seebeck|，而不是电导率

- logPF vs |S|：Pearson +0.47 / Spearman +0.62（n 型）；+0.57 / +0.52（p 型）。
- logPF vs logσ：**-0.22**（负相关！高 σ 反而低 PF）。
- 高 PF(top20%) vs 低 PF(bottom20%)：|S| 202 vs 9 μV/K（**21–29 倍**），而 σ 反而更低（0.82 倍）。

→ **金属（高 σ）的 Seebeck≈0，PF 极低；高 PF 必须来自高 Seebeck 的半导体。**

### 规律 2：电子 ZT 上限 ZT_e^WF = S²/L（固定金属 L 的 WF 上限，定义使然）

- **定义使然**：ZT_e^WF ∝ S² 只含 Seebeck，故「ZT_e 只由 Seebeck 决定、与电导率无关」是公式后果，非独立发现。
- σ 与 κe 的**排序**相关 r≈0.96（WF 一致性方向），但 JARVIS 的 nkappa 与 ncond 数值缩放不一致（≈1e14），不能直接 κe≈LσT 相除（见 40_zte_ceiling.py 单位核对）。
- 真实 ZT = ZT_e^data × κe/(κe+κL)，ZT_e^data = S²σT/κe（需先校准 nkappa 缩放）；κL 只是把 ZT 从 ZT_e 往下压。

### 规律 3：高 Seebeck（= 高 ZT 天花板）需要「宽带隙 + 重有效质量」

| ZT_e 与 | Spearman (n / p) |
|---|---:|
| Eg（带隙） | +0.63 / +0.76 |
| m*（有效质量） | +0.78 / +0.78 |
| D_sigma（维度各向异性） | ~0 |

→ 高 S 来自大带隙（半导体）和重载流子，这是标准热电物理（S ∝ m* × Eg）。

### 规律 4：存在经典的 S–σ 权衡（热电两难）

- ZT_e ∝ S² 倾向「重质量 + 大带隙」（高 S、低 σ）。
- PF ∝ S²σ 还需要「中等 σ」。
- 最优在**中等带隙、中等有效质量**区间，而非极端。

### 规律 5：结构不能用于筛选热电材料

- 即便补强描述符，结构→输运相关仍≈0。**必须计算电子结构（Eg、m*），不能靠结构相似性筛。**

## 四、异常点（需人工核查）

- Cl3Fe（JVASP-6742）：PF=1.3×10⁶（比次高值大 2 个数量级），金属、磁矩大，疑似数值异常。
- CCl18W6（JVASP-20042）：ZT_e=27.9（S=-824 μV/K），Seebeck 反常偏大，疑似异常。

## 五、缺失的关键一环：κ_L

- 真实 ZT = ZT_e × κe/(κe+κL)。**没有 κL，就无法把 ZT_e 天花板折成真实 ZT。**
- 本次已尝试从 C2DB（已迁移到 2dhub.org）和 Alexandria 下载 ZT/κL 数据：
  - C2DB 直接下载 URL（c2db.tar.gz）返回 404（数据需通过其 API/ASR 流程获取）；
  - Alexandria API 端点 404（需查其确切 v2 路径）；
  - figshare 在本环境被 403。
- 下一步要真正得到高-ZT 流形，需要：① 拿到 C2DB/MatHub-2d/Alexandria 的 κL 或 ZT 数据；或 ② 引入 κL 的模型/实验数据（作为 follow-up）。

## 六、对流形+超晶格设计的含义

1. **高 ZT 流形（电子部分）= 高 Seebeck 流形**，即「宽带隙 + 重有效质量」区域（不是结构相似区域）。
2. **超晶格设计需要换锚**：从"结构相似"换成"晶格失配 + 组分相容 + 输运对比"。
   - 晶格失配可用现有 lattice_vectors 直接算（有数据）。
   - 但超晶格的核心收益（界面散射降 κL）**必须有 κL 才能论证**。
3. 当前数据能支撑的是"高 ZT_e 天花板材料池"（本报告第三节），真实 ZT 排名需 κL。
