# 六张总体数据图的逐图说明

## 先说明共同读图规则

这里的“使用全部数据”指：**每个关系使用满足该关系所需字段的最大成对完整样本集**。例如画 `ZT-n` 只要求同一样品有 ZT 和载流子浓度，不会因为它缺少晶格热导而删掉；画 `n-μ` 也不要求该样品必须有 ZT。

- 真实 ZT 图中，每个实验 `sample_id` 只出现一次，取其有效峰值 ZT；横轴物性由同一样品插值到峰值 ZT 的温度，禁止把不同材料拼在一起。
- 六边形颜色表示该区域内样品数的 `log10`；亮色是材料密集区，暗色是稀疏区。
- 白色折线表示横轴分箱后的 ZT/物性中位数，浅色带表示 25%–75% 分位区间。它描述总体中心趋势，不是理论拟合曲线。
- `Spearman rho` 只衡量单调相关；不同材料家族、温度和制备方法混在一起，因此不能直接解释为因果关系或单变量最优值。
- 箱线图红线是中位数，箱体是 25%–75% 分位，须同时看每组的 `N`。图中隐藏离群点只是为了保持尺度可读，原始数值没有删除。

## 图 1：数据覆盖与“到底用了多少数据”

文件：`figures/01_data_coverage.png`

### (a) Starrydata2 各物性的直接实验覆盖

横条统计具有该物性曲线的独立实验样品数。Seebeck 最多（33,950），总热导 22,259，真实非零 ZT 20,037；载流子浓度、迁移率和电子热导明显更少。它解释了为什么后面的每张关系图不能强行使用同一个总样本数。

### (b) 峰值 ZT 温度下的同样品配对数

这是主 ZT 图的实际样本数：`ZT-n` 440、`ZT-S` 12,070、`ZT-σ` 11,738、`ZT-PF` 11,937、`ZT-κL` 3,649、`ZT-κtotal` 11,859。电导优先用直接 σ；没有 σ、但有电阻率时使用 `σ=1/ρ`，所以可配对数可能高于“直接电导曲线”覆盖数。

### (c) 300/600/900 K 的共同温度可用样品

热图逐格显示某个温度和某种物性有多少样品可内插。后面的电子关系图只在同一样品、同一温度内配对，避免温度错配。颜色使用 `log10(N+1)`，格内数字才是精确样本数。

### (d) 额外数据层与缺失项

列出相对密度、粒径、弹性—κL 跨库配对和 JARVIS 2D 输运层。红字明确指出当前源数据没有可直接统计的褶皱幅度/波长、孔洞拓扑、模态声子群速度以及完整声学/光学支标签；这些因素不能伪装成经验总体结论。

## 图 2：真实实验 ZT 与四个核心物性的总体分布

文件：`figures/02_experimental_ZT_global.png`

这是回答“第二张图 a 是否只是一个材料”的主图：**不是单个材料，也不是参数扫描；四个面板都是全部可配对实验样品的总体分布。** 每个样品只在其峰值 ZT 处出现一次。

### (a) ZT 与载流子浓度 n，N=440

横轴是 `log10 n(cm⁻³)`，纵轴是真实峰值 ZT。`rho=-0.18` 表示跨材料总体上只有弱负相关，不能把“n 越低越好”当设计规律。高 ZT 的密集区域主要落在约 `10¹⁹–10²⁰ cm⁻³`，但样本稀少且材料家族混杂，所以它只能给候选窗口，不能给统一最优浓度。

### (b) ZT 与 |S|，N=12,070

`rho=+0.36` 是中等正相关：从很小的 |S| 增大到中等 |S| 时，高 ZT 更常见；但特别大的 |S| 往往对应低载流子浓度和低电导，图中并没有显示“越大越好”。总体高 ZT 密集区大致在 `|S|≈150–500 μV/K`，应与 σ 联合判断。

### (c) ZT 与电导率 σ，N=11,738

横轴是 `log10 σ(S/m)`，`rho=+0.28`。过低 σ 几乎无法得到高 ZT；高 ZT 较常见于约 `10⁴–10⁶ S/m`。更高 σ 同时会提高电子热导 `κe=LσT`，因此白色中位线在高电导端不继续单调上升，这就是电功率因子与电子热漏之间的竞争。

### (d) ZT 与晶格热导 κL，N=3,649

横轴是 `log10 κL(W m⁻¹ K⁻¹)`，`rho=-0.44`，是四个面板中绝对值最大的总体相关。低 κL 明显有利于高 ZT，高 ZT 密集区大致位于亚 1 到约 1–2 W m⁻¹ K⁻¹；但极低 κL 仍不保证高 ZT，因为电子侧可能很差。

## 图 3：不要求有 ZT 的全部电子输运关系

文件：`figures/03_electronic_all_available.png`

每个面板分别使用 300、600、900 K 下同一样品的最大可配对集合。蓝、橙、粉分别表示三个温度；一个样品可在多个温度出现，因此图例同时给面板内观测数。

### (a) Pisarenko 总体分布：n 与 |S|，952 个温度点、820 个样品

总体趋势是 n 增大、|S| 下降，符合简并程度提高后的 Pisarenko 关系。纵向离散反映有效质量、谷简并度、能带非抛物性和材料家族差异；因此同一 n 下较大的 |S| 可作为高态密度有效质量或多谷能带的候选信号，但不能单独识别原因。

### (b) n 与 σ，977 个温度点、824 个样品

总体上 n 增大会提高 σ，因为 `σ=neμ`；同一 n 下跨越数个数量级的散布来自迁移率差异。它说明“提高载流子浓度”只有在迁移率没有被强烈牺牲时才有效。

### (c) n 与迁移率 μ，831 个温度点、705 个样品

高 n 区的 μ 总体下降，可能包含离化杂质、合金、声子和缺陷散射增强，也包含不同材料的本征差异。这个图给出为何 σ 不会永远按 n 线性增长的经验背景。

### (d) n 与功率因子 PF，912 个温度点、788 个样品

PF 结合了 `S²σ` 的竞争：低 n 时 σ 不足，高 n 时 |S| 下降，所以总体中位趋势通常形成宽峰或平台，而不是单调关系。图中的宽平台比单个理论最优点更适合作为跨材料筛选窗口。

## 图 4：不要求有 ZT 的热输运总体关系

文件：`figures/04_thermal_all_available.png`

### (a) 全部实验 κL 曲线的温度分布

共 109,305 个 25 K 网格点、6,317 个样品。深色带是 25%–75%，浅色带是 10%–90%，中线是样品中位数；先对同一样品同温度的重复曲线取中位数，避免某条采点密集的曲线获得额外权重。高温端的中位数变化还会受“哪些样品测到了该温度”的覆盖变化影响，不能把局部上升解释成单一材料 κL 随温度上升。

### (b) κL 与总热导 κtotal，6,495 个温度点、4,945 个样品

虚线是 `κL=κtotal`。物理上通常有 `κtotal=κL+κe`，点应位于或接近虚线下方；偏离反映不同实验拆分方法、插值误差和元数据不一致。κL 接近 κtotal 的区域说明晶格热导占主导。

### (c) κe 与 σ，764 个温度点、582 个样品

斜线是各温度下 `κe=LσT`、取 `L=2.0×10⁻⁸ WΩK⁻²` 的 Wiedemann–Franz 参考。数据沿斜线增长说明高电导会带来电子热漏；点对参考线的偏差对应 Lorenz 数、载流子简并程度或实验拆分差异。

### (d) 声速代理与实验 κL，N=79

横轴 `sqrt(B/ρ)` 是由体模量和质量密度得到的平均声速代理，不是模态群速度；纵轴是约 300 K 的实验 κL。跨库化学式匹配得到 `rho≈+0.62`，支持“更硬、更快的晶格通常有更高 κL”的总体方向。但 N 小且同化学式可能有不同晶型，这一面板只作证据锚点。

## 图 5：实验结构元数据与 ZT/κL

文件：`figures/05_structure_metadata_experimental.png`

### (a) 峰值 ZT 按孔隙率分组，N=1,177

孔隙率由 `1-相对密度` 近似得到。低孔隙组样本最多且 ZT 分布更高，高孔隙组的 ZT 较低；这不等于“孔隙必然有害”，因为高孔隙材料往往属于不同形态、化学体系和接触条件。它说明只降低 κL 而严重损失 σ 时，ZT 仍会下降。

### (b) 峰值 ZT 按晶粒尺寸分组，N=196

五个粒径区间没有稳定单调关系；0.1–1 μm 组中位数较高，但组间样本数很不均衡。晶界既能散射声子、降低 κL，也会散射载流子、降低 μ；因此这里更像竞争区间而不是通用最优粒径。

### (c) 峰值 ZT 按样品形态分组，N=11,288

比较 bulk、polycrystal、single crystal、pellet/compact、film、powder 等报告形态。类别间差异同时包含材料家族、测试方向、致密化和接触误差；箱体用于描述数据库中“哪些形态更常出现高 ZT”，不能解释为形态本身造成的净效应。

### (d) 相对密度与 κL，N=191

六边形显示最大配对样本，`rho=-0.12`，总体关系很弱。相对密度元数据大量集中在 90%–98%，且不少原始记录只是阈值/区间，因此目前不足以单独确定孔隙降低 κL 的定量斜率。

## 图 6：JARVIS 2D 原子几何与输运（不是实验 ZT）

文件：`figures/06_jarvis2d_shape_transport.png`

这一图使用 807 个二维材料、1,609 条 n/p 型 DFT 输运记录；条件固定为 `n=10²⁰ cm⁻³、T=600 K`。它的作用是隔离几何代理与电子输运的关系，不能和图 2 的真实峰值 ZT 混为一谈。

### (a)(b) 面外原子跨度 / sqrt(面内面积)

这个无量纲量越大，表示原子层更厚或更起伏，可近似表征原子尺度 buckling；它不是宏观褶皱幅度。对 n/p 型数据，|S| 与该量只有弱负相关（约 -0.23/-0.14），σ 是中等正相关（约 +0.36/+0.34）。这提示几何起伏可能与轨道耦合和色散相关，但不能证明褶皱提高电导。

### (c)(d) 每原子面内面积

它是面内疏密或骨架开放程度的粗代理，不等于真实孔隙率。与 |S| 的相关很弱（约 +0.12/+0.08），与 σ 为弱负相关（约 -0.25/-0.20）；较开放的原子网络在这组固定条件 DFT 数据中往往电导稍低。

## 与用户提出的结构因素对应关系

| 提出的特征 | 当前可用经验代理 | 结论状态 |
|---|---|---|
| 平面/起伏形状 | JARVIS 2D 面外跨度比 | 可画总体图，但仅是原子尺度 buckling |
| 骨架/疏松结构 | 每原子面内面积 | 可画粗代理，不等于多孔骨架 |
| 是否多孔 | Starrydata2 相对密度推算孔隙率 | 可分组，但元数据较粗 |
| 组成单元是否很软 | `sqrt(B/ρ)` 声速代理中的 B | 仅有小规模跨库验证 |
| 振动频率、群速度 | 没有直接模态数据 | 经验图中删除；只在物理模型层讨论 |
| 声学/光学支及其重叠 | 没有完整分支标签 | 经验图中删除；需 DFPT/Phono3py 数据后再做 |
| 载流子浓度、迁移率、电导、S、PF | Starrydata2 同温度实验曲线 | 已用最大成对样本集绘制 |

因此，图 2–5 是实验总体统计，图 6 是固定条件 DFT 总体统计；原目录 `../figures/` 中的响应面和二次近似仅用于机制推演，不能再被解释为数据库材料总体分布。
